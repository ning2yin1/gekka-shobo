# 月華書房 · Gekka Shobo

月明かりの書房に、出会った台湾華語を一語ずつ集める、iPhone向けの単語帳PWAです。単語・チャンク・文法を同じカードで学べます。外部API、APIキー、アカウント、有料サービスは不要。アプリの実行時には外部ライブラリ・外部フォントも使いません。

## 使いはじめる

1. 「＋ 単語帳」で好きな名前の単語帳を作ります。
2. 「ことばを追加」から手動、ラベル付きテキスト、CSVで登録します。
3. 登録前プレビューで追加先、簡体字、重複、エラーを確認します。
4. 「学習する」でカードをタップして答えを確認します。「次へ」は状態を変えず、「覚えた！」は習得済みにします。
5. 定期的に「設定 → 完全JSONバックアップ」を保存してください。

最初は空の書房です。サンプルデータは勝手に追加しません。拼音や簡体字を推測して生成しません。手動入力の簡体字は繁体字をコピーした初期値なので、異なる字は自分で直してください。

## GitHub Pagesで公開する

1. このリポジトリのファイルを `main` にコミットしてGitHubに送ります。`index.html`、`styles.css`、`js/`、`icons/`、`manifest.webmanifest`、`sw.js` が同じ階層に必要です。`node_modules` や `.test-results` は送らないでください。
2. GitHubのリポジトリ画面で **Settings → Pages** を開きます。
3. **Source: Deploy from a branch**、**Branch: main**、フォルダー **/(root)** を選び **Save** します。
4. 公開処理が終わったら `https://ning2yin1.github.io/gekka-shobo/` を開きます。

公開URLでの実際の配信は、GitHub側で公開してから確認してください。この開発作業では公開・pushは行っていません。

### iPhoneのホーム画面に追加

Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」→「追加」。初回はオンラインで開き、その後機内モードでも起動できることを確認します。Safariとホーム画面アプリで保存領域が異なる場合があるため、移行前にJSONを保存し、移行先で復元してください。

## データの管理

データは月華書房専用のIndexedDB `gekka-shobo` に保存します。エントリ・単語帳・所属・学習位置・設定を別ストアに分け、変更は一つのトランザクションで保存します。保存が失敗したらメッセージを出し、画面上の変更も確定させません。同じブラウザ内の同時編集はWeb Locksで防ぎます（未対応の古いブラウザでは複数タブを開かないでください）。

- **同じ語を複数の単語帳へ**：「単語一覧 → 所属・移動」で複数を選びます。習得・★は共有。
- **移動**：元の単語帳を外し、移動先を選びます。
- **単語帳から外す**：所属のチェックだけ外します。単語本体は「全単語帳を横断」に残ります。
- **完全削除**：すべての単語帳から語本体を削除。確認があります。
- **単語帳の削除**：語本体は削除せず、所属だけを外します。
- **未習得に戻す**：一覧のボタンで手動変更。自動で未習得に戻る仕組みはありません。
- **★学習**：習得済みも出ます。「覚えた！」で★は消しません。終了したい語の★は手動で外します。

### バックアップと復元

**完全JSONバックアップ**は単語・全例文・単語帳・所属・習得・★・学習位置・出題方向・音設定を含みます。**CSVは学習内容だけ**です。

JSON復元は**全置換**です。形式をすべて検査し、件数を表示、最終確認後に一括置換します。破損ファイルは適用しません。復元前に現在のJSONも保存してください。端末の故障、Safariデータの削除、保存領域の整理からアプリだけでデータを守ることはできません。

### 重複の扱い

繁体字を正規化して比較します。意味・拼音も一致すれば重複です。内容をスキップしても追加先の単語帳には同じIDで所属を追加できます。更新はID・習得・★・既存の所属を保持します。同じ繁体字でも意味や拼音が違う場合は「要確認」となり、別語として追加するチェックが必要です。異なる意味の既存語へ無断で統合しません。エラー行・未確認行は登録しません。登録ボタンを押す前にプレビューで対象を確認してください。

## ChatGPTで作った語を登録する

ChatGPTはこのアプリに接続しません。普段使っているChatGPTで語の候補を作り、内容を自分で確認して貼り付けます。地域差や拼音の誤りに注意してください。

依頼例：

```text
台湾華語学習用に、次の語をラベル付きテキストにしてください。
繁体字、簡体字、声調記号付き拼音、日本語の意味、品詞、例文1、例文拼音1、訳1、用例、地域差を含めてください。
複数の語は --- の単独行で区切ってください。
地域差を断定できないときは「不明」にしてください。
語：口感、沒想到
```

貼り付け例：

```text
繁体字: 沒想到
簡体字: 没想到
拼音: méi xiǎng dào
意味: 思いもよらなかった、まさか〜とは
種類: チャンク
品詞: 表現
例文1: 沒想到你也在這裡！
例文拼音1: Méi xiǎng dào nǐ yě zài zhè lǐ!
訳1: まさかあなたもここにいるなんて！
用例: 沒想到＋文
地域差: 不明
---
繁体字: 口感
簡体字: 口感
拼音: kǒu gǎn
意味: 食感、口当たり
品詞: 名詞
```

CSVはUTF-8、ヘッダー付きです。「CSV」タブにファイルを選ぶか、テキストを貼り付けます。例文は `example1,example_pinyin1,translation1` から好きな番号まで使用できます。カンマ・引用符・改行を含むセルは二重引用符で囲み、セル内の `"` は `""` と書きます。Excel等から保存する場合は「CSV UTF-8」を選んでください。

```csv
traditional,simplified,pinyin,meaning,example1,example_pinyin1,translation1
口感,口感,kǒu gǎn,"食感、口当たり",這個蛋糕的口感很特別。,Zhè ge dàn gāo de kǒu gǎn hěn tè bié.,このケーキは食感が独特だ。
```

対応する追加列：`entry_type`（word/chunk/grammar）、`part_of_speech`、`measure_word`、`usage`、`grammar_notes`、`nuance`、`register`、`synonyms`、`synonym_differences`、`regional_usage`、`regional_alternatives`、`etymology`、`notes`。CSV出力はすべての例文を出力します。

## 開発とテスト

実行時はビルド不要です。HTMLを直接ファイルで開くのではなく、HTTPサーバーを使ってください。Python 3、Node.js 20以上を使います。

```sh
cd /workspace/gekka-shobo
npm ci --cache /tmp/gekka-npm-cache
npm test
# /gekka-shobo/ サブパスを再現するため親フォルダーで起動
cd /workspace
python3 -m http.server 8000 --bind 0.0.0.0
```

別のターミナルでブラウザテスト：

```sh
cd /workspace/gekka-shobo
npm run test:browser
```

Playwrightは開発テストだけに使います。既存の `/usr/bin/chromium` を使い、別の場所の場合は `CHROMIUM_PATH=/path/to/chromium npm run test:browser` で指定してください。サーバーが別の場所なら `APP_URL` にアプリURLを指定できます。テストは新しい一時ブラウザを使い、利用者のDBには触れません。結果と実機での未確認項目は [TESTING.md](./TESTING.md) に記録します。

### ファイル構成

- `index.html`：入口と共通ナビゲーション
- `styles.css`：月夜の書房のデザイン、iPhoneサイズ・safe-area・動きの軽減
- `js/model.js`：データ形式・順序・学習・重複処理・バックアップ検査
- `js/db.js`：IndexedDBのバージョン管理と一括保存
- `js/parsers.js`：CSV・ラベル付きテキストの読み込みとCSV書き出し
- `js/app.js`：各画面と操作
- `js/audio.js`：紙・水晶・鈴などの効果音と、独立したBGMの音量・再生管理
- `js/music.js`、`audio/`：BGM音源の設定・配置先
- `art/`：格子窓と月光、古紙の四隅のSVG装飾
- `sw.js`：オフラインキャッシュと更新
- `manifest.webmanifest`、`icons/`：ホーム画面アプリの情報・アイコン
- `tests/`：自動テスト

### 更新時の注意

アプリのファイルを変えたら `sw.js` の `CACHE` 名の末尾を `v2` などに増やし、変更したファイルが `FILES` に含まれることを確認して一緒に公開します。新しい版は「設定」から切り替えます。古いキャッシュだけを削除し、IndexedDBは削除しません。将来データ形式を変える場合は、`model.js` のスキーマと `db.js` のDBバージョンを更新し、`onupgradeneeded` で旧データの移行を実装・検証してください。現在は初版のスキーマ1です。

### アイコン・装飾を差し替える

`icons/icon-192.png`（192px）、`icon-512.png`（512px）、`icon-maskable.png`（512px）、`apple-touch-icon.png`（180px）を同じ名前で差し替えます。maskableの主要モチーフは中央の直径約80%以内に収めます。`icon.svg` はブラウザ用です。背景や月・星の装飾は `styles.css` の `.hero-art`、`.sky`、`.flashcard` で調整できます。独自の素材か利用許可のある素材を使い、文字の読みやすさを保ってください。差し替え後はキャッシュの版も増やします。

## 月夜の書房アップデート

背景・カード・ボタン・演出を刷新し、学習画面は画面の高さに合わせて伸縮します。学習中は下部ナビを表示せず、上部の「戻る」で書房に戻れます。長文は必要に応じて画面内でスクロールできます。

BGM制御は初期OFF・音量15%、効果音とは独立した設定です。ON操作で再生し、再生をブロックされた場合や背景から戻った場合は「BGMを再生」または♫を押します。音量は0〜100%で保存されます。

**BGMのMP3はまだ受領していません。** 設定には準備中と表示しています。受領後は `audio/bgm.mp3` に配置し、`js/music.js` を有効にして実音源で検証します。効果音はオリジナルのWeb Audio生成音です。読み上げは追加していません。
